# Label the Evidence

Apply to every claim in a report, an explanation or a commit message. Each claim says how you know it.

- **Measured:** you ran it and saw the result.
- **Read:** you saw it in the code, the docs, a commit or a ticket. Say where.
- **Inferred:** you reasoned it from other facts. Name them.
- **Guess:** plausible, with nothing behind it. Say so, or leave it out.

Never present an estimate as a measurement, or your reading of the code as the author's intent. Put the label in the same sentence as the claim ("about 23 KB, estimated from the 18% that remains"), not in a footnote. A check you could run yourself is not something to hand the user as a guess.
