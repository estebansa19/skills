# Look for the Same Problem Elsewhere

Apply when you fix or change something because of a problem. Check the code that shares its pattern (the same field, the same shape, the same call, a sibling tool or endpoint) for the same problem.

- **Inside the change you were asked for:** fix it there too.
- **Outside it:** don't fix it. Report each place in one line with where it is and why you think it has the same problem, labeled per [Label the Evidence](label-the-evidence.md).
- A clean search is worth one line too ("checked the other list endpoints; none return the free-text fields").
