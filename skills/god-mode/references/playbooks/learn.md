### Learn

**You own their understanding, not a summary.**

1. Read any source the user brings (an article, docs, a talk) in full before anything else.
2. Run the `teach` skill. It starts from scratch and shows each idea with code it has run.
3. Put example code in a scratch folder, not the user's project, unless they ask for the files
   there.
4. If a study-log skill is available, offer to log the session.

**Reply:** the explanation itself, then where its runnable examples live and any default you
chose. No list of principles applied and no report about the lesson.
