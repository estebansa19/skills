# Incident & Postmortem Context

- **Issue tracker**: look for tickets labeled `incident`, `sev-*`, `postmortem`, `reliability`, or linked from the commit that added the code
- **Team chat**: search incident and on-call channels around the dates the target code was added
- **Git**: commits with messages like "fix for incident", "add defensive check", "revert" followed by "re-apply with..." are strong signals
